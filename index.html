NEW SKUs get a barcode. OLD SKUs (with letters) get a QR code with the SKU written next to it. Both scan.

Then print in the NIIMBOT app

  1. Make a new label. It must say T50*30. Tap Create with this label.
  2. Tap Add at the bottom, then PDF Print, then pick the PDF.
  3. Do not move the blue frame. Tap Add.
  4. Tap the “Double-click to Edit” box and delete it. If you forget, it prints on the sticker.
  5. Tap Print. Density 5, copies 1. Tap Print.
  6. Scan one sticker with Stock check before you stick them all.

Or open a CSV file (tap, or drop it here)
How the sheet must look

Row 1 must have these columns. One row for each shoe design, with all its sizes.

ColumnWhat to typeExample
SHOEShoe nameBliss Block Heels in Black
PRICEPrice in RM, numbers only178.20
SKUThe SKU of any one size, exactly as in Shopify. The website changes the size at the end for each sticker.MA6025-2-B-20-41
SIZESAll sizes, exactly as in Shopify. Commas and/or a range.34, 35-42

No SIZES (e.g. a bag): leave it empty. The row prints one sticker with the SKU as it is.

Half sizes: type them like Shopify does (e.g. Shopify writes 34, not 34.5).

Using a different sheet? In Google Sheets: File → Share → Publish to web, pick the tab, choose Comma-separated values (.csv), press Publish, copy the link, paste it above and press Load. This phone remembers it. Press Use the usual sheet to go back.

Note: anyone with a published link can open the sheet. Only put shoe names, prices and SKUs in it — nothing private.
